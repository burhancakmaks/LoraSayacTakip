# Lora Sayaç Takip

MASKİ su sayaçlarının harita üzerinden takip edilmesini sağlayan Next.js tabanlı yönetim paneli.

## Özellikler

- Harita üzerinde bina ve sayaç konumlarının görüntülenmesi
- Sayaç ve abone bilgilerinin yönetimi
- Bina detayları ve zemin kat bilgisi takibi
- Karanlık / aydınlık tema desteği

## Teknolojiler

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- Leaflet

## Kurulum

```bash
npm install
npm run dev
```

Uygulama varsayılan olarak [http://localhost:3000](http://localhost:3000) adresinde çalışır.
